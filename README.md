One haiku about debugging, seventeen syllables, 5-7-5:

> Cursor blinks, midnight,
> the log insists nothing broke
> the bug wore my face.

The cursor blinks at midnight, the log swears everything is fine — and the turn: the bug was never in the code. It was wearing my face all along.

## Run it

```sh
python3 main.py
```

Writes the haiku to `/output/entry.txt` (or to the path given as the first argument).
